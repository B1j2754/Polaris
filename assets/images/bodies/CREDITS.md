# Solar-system portraits

Bundled previews for the bodies the DSS2 survey cutouts cannot frame (see `src/components/object-preview.tsx`).
Each is a NASA image in the public domain, downscaled and letterboxed to a 600x600 JPEG to match the
CDS hips2fits cutouts used for fixed targets. NASA material is not protected by copyright; the agency asks
only that it not be used to imply endorsement — https://www.nasa.gov/nasa-brand-center/images-and-media/
